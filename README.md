# Quản lý chi tiêu cá nhân

Một dự án web nhỏ giúp theo dõi thu chi hằng ngày ngay trên trình duyệt.

## Chức năng

- Thêm khoản thu và khoản chi
- Xem tổng thu, tổng chi, số dư hiện tại
- Hiển thị danh sách giao dịch
- Xóa từng giao dịch hoặc xóa toàn bộ
- Lưu dữ liệu bằng `localStorage`

## Công nghệ sử dụng

- HTML
- CSS
- JavaScript

## Cách chạy dự án

1. Tải mã nguồn về máy
2. Mở file `index.html` bằng trình duyệt

## Gợi ý cải thiện tiếp

- Thêm bộ lọc theo ngày
- Thêm biểu đồ thu chi
- Thêm phân loại danh mục
- Kết nối cơ sở dữ liệu để lưu lâu dài
